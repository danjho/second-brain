# Log

Registro append-only; nunca reescreva entradas antigas. Mais recente no fim.

Registre só o que for importante e útil no futuro (decisões, reorganizações, consolidações, revisões). Não registre edições rotineiras: o git já guarda esse histórico.

Formato: `YYYY-MM-DD | ação | [[nota ou caminho]] | motivo`
Ações: `criou`, `atualizou`, `moveu`, `consolidou`, `obsoletou`, `revisou`.
